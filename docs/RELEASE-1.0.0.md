# GPU-PRO 1.0.0

## Fedora 45 e GNU GPLv3

O GPU-PRO 1.0.0 inaugura a distribuição do código original sob
[GNU GPL versão 3](https://github.com/eritongrnascimento-svg/GPU-PRO/blob/main/LICENSE)
e acrescenta um RPM nativo para Fedora 45 x86_64. Telemetria, benchmarks,
HUD e perfis continuam disponíveis.

O código pode ser estudado, modificado e redistribuído nos termos da GPLv3.
Distribuições independentes devem usar nome e logotipo próprios, conforme a
[política de marcas](https://github.com/eritongrnascimento-svg/GPU-PRO/blob/main/TRADEMARKS.md).
As dependências preservam suas licenças e avisos.

No Fedora 45, instale com:

```sh
sudo dnf install ./gpu-pro-1.0.0-1.fc45.x86_64.rpm
```

A distribuição Linux inclui DEB para Ubuntu 24.04, AppImage para sistemas
x86_64 compatíveis com glibc 2.39 ou posterior, e os formatos RUN e TAR.
Consulte SHA256SUMS.txt e as fontes correspondentes às bibliotecas do AppImage.
A série 0.8.1 mantém os arquivos e os termos com que foi publicada.
